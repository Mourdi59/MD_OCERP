# Module intro copy deck

This file is the single source of truth for the in-app info-block copy that sits at the
top of each module page. The English strings here are what the i18n keys
`<feature>.intro_title` and `<feature>.intro_body` resolve to. Translators take these
English values as the source text and produce the 26 other locales from them.

Two rules shape every line:

- **intro_title** = the pain the page closes, written as 4 to 9 words. It never repeats the
  module name, never uses an em-dash, and never ends in an exclamation mark. Titles are kept
  varied across the deck so the app does not read like ninety pages that all open with "Stop".
- **intro_body** = one to three sentences that say what goes in, what comes out, and where the
  result flows next. Claims are limited to what the page actually does today; anything that
  could not be confirmed in source is held back and noted in the Notes column as [VERIFY]
  rather than shipped.

The deck is grouped by sidebar cluster. Routes that appeared in more than one cluster draft
have been deduplicated to a single canonical entry (the better-grounded wording wins); see the
Implementation notes at the end for the merge decisions.

## Implementation notes

### Key naming convention

Every entry maps to two i18n keys, `<feature>.intro_title` and `<feature>.intro_body`, where
`<feature>` is the Feature column value (the page's feature folder / module key, not the route).
Where a block exists today under a different key (for example `info.boq.title`,
`rfi.info_title`, `crm.pipeline_intro`, `service.intro_title`), the wave should converge on the
`<feature>.intro_title` / `<feature>.intro_body` pair so the source of truth is uniform, and
leave a one-release alias on the old key if it is referenced elsewhere. Routes that share a
feature folder (for example `/bim`, `/bim/federations`, `/bim/rules` under `bim`, or the three
`/accommodation` routes) need per-page suffixes so they do not collide, for example
`bim.intro_title`, `bim_federations.intro_title`, `bim_rules.intro_title`.

The English strings in this deck are the source text only. Every `intro_title` and `intro_body`
added or changed here must be translated into all 26 non-English locales
(ar, bg, cs, da, de, es, fi, fr, hi, hr, id, it, ja, ko, mn, nl, no, pl, pt, ro, ru, sv, th, tr,
vi, zh) before the strings ship, so all 27 locales stay at full coverage. Run the i18n sweep
after merging and confirm no TS1117 duplicate-key errors and no raw-key or residual-English leaks
on screen per locale. Two pages already carry hardcoded English copy in source
